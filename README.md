## 🎨 **Design System**

### 🎨 **Color Palette**
```css
Primary Gradient: Pink (#EC4899) → Cyan (#06B6D4)
Background: Dark Slate (#0F172A, #1E293B)
Text: White (#FFFFFF), Gray-300 (#D1D5DB)
Status Colors: Blue, Yellow, Purple, Orange, Green
```

### 🔤 **Typography**
- **Headings**: Space Grotesk (Modern, Bold)
- **Body**: Poppins (Clean, Readable)
- **Responsive**: Scales perfectly across devices

### 📐 **Responsive Breakpoints**
- **Mobile**: < 640px (Single column, touch-optimized)
- **Tablet**: 640px - 1024px (Two columns, balanced)
- **Desktop**: > 1024px (Full layout, hover effects)

## 🔧 **Customization Guide**

### 🎥 **Update Video Content**
```typescript
// src/components/VideoShowcase.tsx
const showcaseVideos = [
  {
    platform: "youtube",
    videoId: "YOUR_VIDEO_ID",        // ← Replace this
    link: "https://youtube.com/...", // ← And this
  }
];
```

### 📧 **Setup Contact Form**
```env
# .env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id  
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

### 🎨 **Brand Colors**
```javascript
// tailwind.config.js
colors: {
  pink: { 600: '#YOUR_PRIMARY_COLOR' },
  cyan: { 600: '#YOUR_SECONDARY_COLOR' },
}
```
